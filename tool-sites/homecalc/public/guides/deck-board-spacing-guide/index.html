Deck guide

Deck board spacing basics for material estimates.

Deck board count depends on actual board width plus the gap, not the nominal lumber name printed on a shelf tag.

Use actual width

A board sold as 1x6 or 5/4x6 may not be six inches wide. The actual face width is often closer to 5.5 inches, and composite boards have their own dimensions. The deck board calculator uses actual face width plus the planned gap to estimate rows across the deck.

Spacing also affects drainage, debris, seasonal movement, and manufacturer warranty requirements. Do not choose a gap only to make the math look better.

When to increase waste

A simple rectangular deck with boards running full length can use a modest allowance. Increase waste for diagonal patterns, border boards, stair treads, boards with visible defects, or layouts that need color and grain sorting.

  • Confirm joist spacing and board span limits.
  • Include fasteners, plugs, clips, and starter boards.
  • Plan picture-frame borders separately.
  • Include railing and stair materials outside board count.
  • Check local permit and structural requirements.
